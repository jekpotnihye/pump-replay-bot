A defensive paper-money trading bot for the Pump.fun replay: it trades 10 SOL of paper money on recorded Solana chain data, entering only confirmed, liquid coins in tiny sizes and exiting on take-profit, stop-loss, trailing fall, or a holding-time limit. Nothing is traded for real.

## Run it

```sh
node main.ts
```
